# Third-party software

The MIT license covers PryOS scripts, config, docs, and the wallpaper. Ubuntu, XFCE, Node.js, the recovery tools, and the agent clients keep their own licenses.

The build downloads those programs. They are not stored in this repo. License files stay inside the image under `/usr/share/doc` and with each upstream package.

| Software | Source |
| --- | --- |
| Ubuntu packages and kernel | [Ubuntu licensing](https://ubuntu.com/legal/intellectual-property-policy) |
| XFCE | [XFCE](https://www.xfce.org/about) |
| Node.js | [Node license](https://github.com/nodejs/node/blob/main/LICENSE) |
| Codex | [OpenAI Codex](https://github.com/openai/codex) |
| Claude Code | [Claude Code](https://code.claude.com/docs/en/legal-and-compliance) |
| Gemini CLI | [Gemini CLI](https://github.com/google-gemini/gemini-cli) |
| OpenCode | [OpenCode](https://github.com/anomalyco/opencode) |

You bring your own accounts for the agents. Check the licenses of the versions you built before you give the ISO to anyone else.
