# Changelog

## 0.1.0 — initial public source

- Ubuntu-based nonpersistent amd64 recovery image with a root XFCE desktop.
- PryOS boot menus, image branding, hostname and artwork.
- Helium default browser with an unprivileged browser identity and sandbox retained.
- Recovery desktop launchers plus Codex, Claude Code, Gemini CLI and OpenCode.
- Linux builder, Windows/WSL2 wrappers, macOS/Lima helper and QEMU boot helper.
- Source/integrity checks, contribution templates and platform documentation.
