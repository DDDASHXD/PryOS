# Changelog

## 0.1.0

First public source release.

- Ubuntu 24.04 live image with an XFCE desktop that logs in as root
- Disk and Windows recovery tools
- Codex, Claude Code, Gemini CLI, and OpenCode
- Build scripts for Linux, Windows, and macOS
- x86-64 image (`pryos-amd64.iso`) and ARM64 image (`pryos-arm64.iso`)
